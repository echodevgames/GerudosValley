# Gerudos Valley | Founding Source Pack
**Version:** 0.4 draft | **Date:** 2026-11-10

Start here. This pack distinguishes agreed direction from provisional details. Nothing here claims a guild or server has been established.

## File map
- `docs/01_PROJECT_SOURCE.md`: authoritative project context for a new ChatGPT project.
- `docs/02_GUILD_CODEX.md`: future officer / onboarding policy reference.
- `docs/03_ROADMAP.md`: phased founding and operational milestones.
- `docs/04_PRE_INVITE_CHECKLIST.md`: exact preparations before inviting anyone.
- `docs/05_PUBLIC_MANIFESTO.md`: short public copy for the landing page and Discord.
- `docs/06_LORE_AND_BRAND.md`: verified Zelda inspirations, original flavor text, and boundaries against accidental lore claims.
- `index.html`: ready-to-publish single-file GitHub Pages starter; replace placeholder Discord invite and update openings. (`site/index.html` is a convenience copy.)

## Authority order
1. Explicit founder decisions made after this pack is written.
2. `01_PROJECT_SOURCE.md` (decision register, scope, unresolved decisions).
3. `02_GUILD_CODEX.md` for day-to-day operations.
4. `03_ROADMAP.md` and `04_PRE_INVITE_CHECKLIST.md` for implementation.
5. `06_LORE_AND_BRAND.md` for creative identity (noncanonical), subordinate to membership and operating rules.
6. `05_PUBLIC_MANIFESTO.md` and website: outward summary, not authority for officer decisions.

Do not publish internal officer procedures, attendance records, or member information on the public website.
